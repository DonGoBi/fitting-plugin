👗 V-FITTING: 쇼핑몰 모델 컷에 내 사진 겹쳐보기
"이 옷, 내가 입으면 어떤 느낌일까?"

쇼핑몰 모델 사진을 보며 고민만 하던 시간은 이제 끝! V-FITTING은 웹 브라우저에서 모델 컷 위에 내 사진을 직접 겹쳐보며 스타일과 핏을 실시간으로 확인하는 '나만의 가상 피팅룸'입니다.

✨ 이런 기능들이 있어요
1. 실시간 사진 합성 & 피팅
내 사진 바로 올리기: 준비한 내 사진을 업로드해 쇼핑몰 페이지 위에 바로 띄울 수 있습니다.

자유로운 위치 이동: 마우스 드래그로 모델의 위치에 맞춰 내 사진을 이리저리 옮겨보세요.

좌우 반전 & 한 번에 초기화: 모델이 서 있는 방향에 맞춰 사진을 반전시키거나, 클릭 한 번으로 모든 설정을 처음으로 되돌릴 수 있습니다.

2. 정교한 편집 도구
지우개로 누끼 따기: 사진 배경을 슥슥 지워 모델 옷과 자연스럽게 합성해 보세요. (브러시 크기도 조절 가능!)

조명에 맞춘 톤 보정: 밝기, 대비, 채도를 조절해 쇼핑몰 조명과 내 사진의 톤을 찰떡같이 맞출 수 있습니다.

디테일한 배치 조절: 사진 크기를 키우거나 고개 각도에 맞춰 사진을 살짝 기울여 보세요. 투명도를 낮추면 모델의 원래 포즈와 더 정확하게 맞출 수 있습니다.

3. 나만의 룩북 관리
넉넉한 6개 저장 공간: 마음에 드는 코디 조합을 최대 6개까지 저장해 두고 언제든 다시 꺼내 보세요.

이름 붙여 저장하기: '하객룩 코디', '린넨 셔츠'처럼 나만의 이름을 붙여서 관리할 수 있습니다.

4. 깔끔하고 편리한 사용성
세련된 리모컨: 다크 모드 기반의 직관적인 컨트롤 패널로 모든 기능을 한눈에 제어합니다.

작게 접어두기: 작업 중 화면을 가리지 않도록 리모컨을 최소화할 수 있습니다.

원클릭 전원 스위치: 필요할 때만 켜서 쓰세요. 기능을 끄는 즉시 브라우저 리소스를 반환해 PC 성능에 영향을 주지 않습니다.

🛠 설치 및 사용 방법
이 프로젝트를 다운로드하거나 클론합니다.

Bash
git clone https://github.com/username/v-fitting.git
크롬 주소창에 chrome://extensions/를 입력해 접속합니다.

우측 상단의 [개발자 모드]를 켭니다.

[압축해제된 확장 프로그램을 로드합니다]를 눌러 프로젝트 폴더를 선택하면 끝!

📁 파일 구조
manifest.json: 확장 프로그램의 뼈대 설정 및 권한 관리

content.js: 메인 피팅 로직과 이벤트 처리

styles.js: 리모컨과 아바타 UI 디자인

templates.js: UI 구조 설계

popup.html / .js: 기능 ON/OFF 제어 팝업

icons/: 사이즈별 전용 아이콘 이미지

🚀 기술 스택
JavaScript (ES6+), HTML5, CSS3

Chrome Extension API (Manifest V3)

Storage API (사진 저장을 위한 무제한 용량 권한 사용)
